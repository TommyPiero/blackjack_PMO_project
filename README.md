# Blackjack project - Java Swing
Software that implements the Blackjack game in **Java**, developed for PMO exam.

## Functionality
At the start, the program shows a panel with a choice between two modes:
1. **Graphic Mode:** GUI desktop developed using **Java Swing**.
2. 2. **Text Mode:** CLI version.

## Architecture and Structure
* **MVC Pattern:** The code is structured by separating data logic (**Model**), visual screens (**View**), and input handling (**Controller**).
* * **Resource Management:** Playing card images are dynamically loaded.

## How to start the game
1. Import the project into the IDE.
2. Open and run the main file containing the `main` method (`LauncherGeneralMain.java`).
